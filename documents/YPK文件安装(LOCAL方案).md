# YPK文件安装（LOCAL方案）

## 方案概述
LOCAL方案是将YPK软件包直接安装到系统目录的安装方式，适用于需要系统级集成的软件安装。相比虚拟环境方案，LOCAL方案提供更深度的系统集成，但需要谨慎处理安全性问题。

## 安装流程

### 1. 创建临时目录
- 使用 `tempfile.mkdtemp(prefix="ypk_extract_")` 创建临时目录
- 临时目录自动管理，避免工作目录污染
- 格式：`/tmp/ypk_extract_xxxxx/`

### 2. 解压YPK文件
将YPK文件解压到临时目录：
```bash
tar xvf package.ypk           # 解压YPK外层
xz -d -c pkgdata | cpio -idu  # 解压数据包
tar xvf pkginfo               # 解压信息包
```

### 3. 安全过滤
在复制文件前进行安全检查，排除危险文件：

#### 排除规则
- **pk开头的文件**：可能包含系统关键文件
- **路径含有dbus的文件**：避免影响系统消息总线
- **路径含有polkit的文件**：防止权限系统被篡改

#### 过滤实现
```python
def should_exclude_file(file_path, file_name):
    # 排除pk开头的文件
    if file_name.startswith('pk'):
        return True
    
    # 排除路径中含有dbus或polkit的文件
    lower_path = file_path.lower()
    if 'dbus' in lower_path or 'polkit' in lower_path:
        return True
    
    return False
```

### 4. 目录映射与安装
将解压后的目录按照安全规则映射到系统目录：

| 源目录 | 目标目录 | 说明 |
|--------|----------|------|
| usr | /usr/local | 避免覆盖系统/usr目录 |
| etc | /usr/local/etc | 配置文件隔离 |
| var | /var | 系统变量数据 |
| opt | /opt | 可选软件包 |
| tmp | /tmp | 临时文件 |

### 5. 递归合并文件
使用安全的合并算法复制文件：
- 检查每个文件的安全性
- 递归处理子目录
- 保持文件权限和时间戳
- 跳过危险文件并记录日志

### 6. 清理临时目录
安装完成后自动清理临时目录：
```python
finally:
    if temp_dir and os.path.exists(temp_dir):
        shutil.rmtree(temp_dir)
```

## 安全特性

### 1. 临时目录隔离
- 使用系统临时目录，避免工作目录污染
- 自动清理，防止残留文件
- 唯一目录名，避免冲突

### 2. 文件过滤机制
- 主动排除潜在危险文件
- 保护系统关键组件
- 提供详细的跳过日志

### 3. 路径安全映射
- usr目录映射到/usr/local，避免系统文件冲突
- etc目录隔离到/usr/local/etc
- 保持目录结构的一致性

### 4. 异常处理
- 完整的错误捕获和处理
- 失败时自动清理临时文件
- 详细的错误信息输出

## 优势

### 1. 系统集成度高
- 软件完全集成到系统环境中
- 可被其他系统工具发现和使用
- 符合Linux文件系统标准

### 2. 性能优势
- 无需额外的环境变量设置
- 直接访问系统库和资源
- 启动速度更快

### 3. 依赖管理
- 可利用系统已有的依赖库
- 减少重复安装
- 节省磁盘空间

### 4. 安全保障
- 多层安全过滤机制
- 临时目录隔离
- 异常情况自动清理

## 风险与注意事项

### 1. 系统风险
- ⚠️ 需要root权限
- ⚠️ 可能影响系统稳定性
- ⚠️ 错误的包可能破坏系统

### 2. 依赖冲突
- 可能与系统软件产生依赖冲突
- 版本不兼容问题
- 库文件冲突

### 3. 卸载复杂
- 需要手动跟踪安装的文件
- 卸载不彻底可能残留文件
- 缺乏包管理器的卸载机制

### 4. 安全建议
- 仅安装来自可信来源的YPK包
- 安装前检查包的内容和权限
- 定期备份系统关键文件
- 在测试环境中先验证

## 与虚拟环境方案对比

| 特性 | LOCAL方案 | 虚拟环境方案 |
|------|-----------|-------------|
| 安装位置 | 系统目录 | 用户目录 |
| 权限要求 | root | 用户权限 |
| 系统集成 | 高 | 低 |
| 安全性 | 中等 | 高 |
| 卸载难度 | 高 | 低 |
| 性能 | 优 | 良 |
| 隔离性 | 差 | 优 |

## 推荐使用场景
